# Test and evidence policy — draft

Proposed minimal commands: install, lint, typecheck, unit test, production build, Playwright smoke. Actual scripts defined in M01; do not claim these work until executed.

Every milestone completion report records commands, pass/fail, executed environment, screenshots where material, commit SHA, deployed URL, and acknowledged limits.

M04 mandatory E2E: admin sign-in; create draft project; read/edit; publish; public detail visibility; delete and confirm absence; anonymous direct-write rejected; non-admin direct-write rejected; validation errors displayed.

M08: keyboard-only journey, focus states, axe automated audit, reduced-motion, mobile viewport regression, public metadata and Lighthouse results with measured device/settings.

M09: repeat security tests, build in CI, secret scan and free-tier failure/recovery exercise.
