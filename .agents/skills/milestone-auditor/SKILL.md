# Milestone Auditor
Compare the actual git diff to the approved plan; inventory changed files, successful and failed commands, screenshots, URLs, auth/RLS attack checks, performance regressions and deviations. Document blockers and residual risks faithfully; never invent test results. Record findings in the milestone completion report and give a reproducible demonstration. The owner and ChatGPT, not this skill, accept the milestone.
