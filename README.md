# Portfolio Project Blueprint — Draft v0.1

This is a **planning-only reference pack**, not an initialized web application. No code, deployment, account or remote repository was created. Use `prompts/M00_PLAN_ONLY.md` in Antigravity to request a plan. Return that plan to ChatGPT for review. Do not implement before approval.

## North star
An evidence-led personal software-engineering portfolio with a public site and an administrator-only CMS. Academic CRUD must be real, secure, demonstrable, and deployed early.

## Process
1. Read `AGENTS.md`, then `docs/MEMORY.md`, `docs/ROADMAP.md` and the milestone's approved plan.
2. Ask Antigravity for a **plan only**. Review with the human and ChatGPT.
3. After approval only, use `prompts/IMPLEMENT_TEMPLATE.md` for code.
4. Run checks, save a milestone completion report, supply git commit and deployed URL (when applicable).
5. ChatGPT performs acceptance review; proceed only after approval.
